# Verification record

Validated in local managed Linux using Node 24.22.1, PostgreSQL 17, Next.js 16.4.6 and system Chromium.

- Production compilation and TypeScript checking passed.
- Seven PostgreSQL integration tests passed against a temporary database using the restricted runtime role: concurrent withdrawals/nonnegative balances; server/database authorization; transfer conservation/immutable history; independent approvals and partial/idempotent receiving; checkout/return limits; deferred reconciliation for transfers/receipts; serialized asset uniqueness while checked out.
- Browser checks passed at 1440px desktop and 390px mobile: sign in, dashboard, inventory search, laboratory tabs, reporting period selection, PDF and Excel download signatures, and no page-level horizontal overflow. Screenshots were visually inspected against the supplied prototype. One mobile overflow defect was found and fixed by constraining grid children and scrolling tables within panels.
- Runtime dependency audit reports zero known vulnerabilities after overriding ExcelJS's transitive uuid dependency to a patched compatible version. This is a point-in-time package audit, not a penetration test.
- Sample reports and browser screenshots are generated by `npm run test:browser`; example output lives under `work/qa/` in the development checkout.

Not validated: production hosting, university SSO/MFA, university finance or facilities data, formal accessibility certification, tagged PDF accessibility, USG reporting compliance, high-load behavior, backup restoration or institutional approval. See PRODUCTION.md. No production systems were contacted and nothing was publicly deployed.
